## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Clique no elemento errado do relógio | onClick fica em `span.tiktok-timepicker-left/right`, não no `div.option-item`; clique no div (nativo ou JS) é ignorado | blocking | Usar `_TIME_SPANS`; rolar só a lista (`_JS_SCROLL_IN_LIST`) — rolar a página fecha o popup |
| Conferir antes de o valor assentar | Hora só grava ao fechar o relógio; prefill do nome do arquivo sobrescreve a descrição com atraso | blocking | `_close_time_popup` antes de conferir; descrição re-digitada e conferida até 3x |
| Confiar na tiktok-uploader 1.1.5 | `_set_video` em thread + Event trava para sempre em erro; seletores mortos | blocking | Fluxo por vídeo é `_studio_complete_upload_form` (patch em `_patch_tiktok_uploader`) |
| webdriver_manager p/ Edge | Usa msedgedriver.azureedge.net (fora do ar) → "Could not reach host. Are you offline?" | advisory | `_start_with_selenium_manager` (Selenium Manager primeiro) |
| Testar com python global | Python global tem tiktok-uploader 1.2.0 (Playwright) e sem selenium | advisory | Usar `G:\DarkAgent\venv` ou venv isolado com 1.1.5 |
